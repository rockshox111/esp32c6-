ESP32-C6 无触控 SD RTOS 微系统

FreeRTOS调度LVGL中文UI SD文件管理CPU/内存监控 按键交互图标+中文子集
⬇ 下载完整工程（ZIP）

适配微雪 ESP32-C6-LCD-1.47（ST7789 172×320，板载SD，无触控）。 解压后配引脚即可 idf.py build。

快速开始

idf.py set-target esp32c6
idf.py menuconfig
idf.py build
idf.py -p 你的串口 flash monitor

引脚（已按开发板填好）

LCD: MOSI6 SCLK7 CS14 DC15 RST21 BL22
SD : MISO5 MOSI6 SCLK7 CS4
KEY: OK9 UP10 DOWN11 BACK8

功能

  • FreeRTOS 多任务：GUI / SD / 系统监控解耦
  • LVGL 中文界面：首页、文件管理、文本查看、CPU/内存/任务监控
  • SD FAT 文件浏览、翻页、打开文本、删除、写日志
  • SPI+DMA 局部刷新、中文子集字体、图标预建对象、异步写日志
